# DXF Survey

تطبيق Android بلغة Kotlin بدون مكتبات خارجية لفتح ملفات DXF وعرضها وتعديلها ومعالجة حسابات مساحية.

## الميزات
- فتح ملفات DXF وعرضها مع تكبير وتصغير (بقرص الإصبعين) وتحريك (بسحب إصبع واحد).
- تحديد الكيان بالنقر عليه، ثم سحبه لنقله.
- تعديل نص كيان TEXT، وتعديل إحداثيات النقطة الأولى.
- تراجع (Undo) عن التعديلات.
- حفظ الناتج كملف DXF جديد، دون تغيير الملف الأصلي.
- حاسبة مساحية: الاتجاه = atan2(dE, dN) بالغراد، والزاوية الأفقية = اتجاه الهدف − اتجاه التصفير، مع تطبيع ضمن 0 إلى 400.

## الكيانات المدعومة
POINT, LINE, CIRCLE, TEXT, LWPOLYLINE. أي كيان آخر يبقى في الملف كما هو دون تعديل ولا يُعرض.

## البناء
- عبر GitHub Actions: يبني الملف `build.yml` نسخة debug من APK مع كل push إلى main. حمّل الـ APK من تبويب Actions ثم Artifacts.
- محلياً: افتح المشروع في Android Studio ونفّذ Build > Build APK.

## الوحدات
- `DxfModel.kt`: قراءة الملف وتقسيمه إلى ترويسة وقسم ENTITIES وذيل، وتسلسل الكيانات كأزواج group code.
- `DxfView.kt`: الرسم واللمس والتكبير والتحريك والتحديد.
- `Survey.kt`: الحسابات المساحية بالغراد.
- `MainActivity.kt`: الواجهة وفتح الملفات وحفظها والتراجع.
