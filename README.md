# DXF Survey

تطبيق Android بلغة Kotlin بدون مكتبات خارجية لفتح ملفات DXF وعرضها وتعديلها وإجراء الحسابات المساحية.

## الميزات
- عرض كل كيانات الملف: POINT, LINE, LWPOLYLINE, POLYLINE, CIRCLE, ARC, ELLIPSE, SPLINE, TEXT, MTEXT, SOLID, 3DFACE, وINSERT مع تعريفات الكتل.
- تكبير وتصغير بقرص الإصبعين، وتحريك بسحب إصبع واحد.
- تحديد كيان بالنقر عليه، ثم سحبه لنقله.
- تعديل نص TEXT/MTEXT، وتعديل إحداثيات النقطة الأولى.
- التقاط النقاط من الشاشة بنوع محدد: بداية، منتصف، نهاية، أو نقطة.
- تراجع (Undo) عن التعديلات.
- حفظ الناتج كملف DXF جديد، دون تغيير الملف الأصلي.

## الحسابات المساحية (بالغراد، والمسافات بالمتر)
- **التوقيع:** الاتجاه = atan2(dE, dN). الزاوية الأفقية من التصفير مع عقارب الساعة = اتجاه الهدف − اتجاه التصفير، مع تطبيع ضمن 0 إلى 400. تُحسب المسافة من المحطة إلى الهدف.
- **المسح التفصيلي:** من المحطة والتصفير والزاوية والمسافة تُحسب إحداثيات النقطة E وN.

## الحدود المعروفة
- HATCH وDIMENSION وغيرها من الكيانات غير المذكورة أعلاه لا تُرسم، لكنها تبقى في الملف الناتج كما هي.
- SPLINE يُرسم كخط يمر بنقاط التحكم، وهو تقريب وليس المنحنى الحقيقي.
- التعديل على الإحداثيات يطبّق على النقطة الأولى فقط.

## البناء
- عبر GitHub Actions: يبني `build.yml` نسخة debug من APK مع كل push إلى main. حمّل الـ APK من تبويب Actions ثم Artifacts.
- محلياً: افتح المشروع في Android Studio ثم Build > Build APK.

## الوحدات
- `DxfModel.kt`: قراءة الملف وتقسيمه إلى ترويسة وقسم ENTITIES وذيل، وتعريفات الكتل، وتحويل الكيانات إلى أشكال قابلة للرسم.
- `DxfView.kt`: الرسم واللمس والتكبير والتحريك والتحديد والالتقاط.
- `Survey.kt`: الحسابات المساحية.
- `MainActivity.kt`: الواجهة وفتح الملفات وحفظها والتراجع ولوحة المساحة.
